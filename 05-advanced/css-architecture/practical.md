## Lesson and lab

Inventory the task board's buttons, inputs, cards, and alerts. Create a demo page showing each in default, focus, disabled, error, and long-content states.

1. Define spacing, color, type, and radius tokens.
2. Implement button variants through a shared base class and explicit modifiers.
3. Build form-field markup with a persistent label and associated error text.
4. Add a responsive task card without a fixed height.
5. Replace duplicate styles in the application, checking each affected screen.

Test keyboard navigation, 200% text zoom, a 320 CSS-pixel viewport, long unbroken content, and reduced-motion preferences. Record screenshots and actual failures. A screenshot alone does not prove accessibility: inspect names, focus order, and error announcements too.

Deliver the demo, token definitions, and a short usage guide. Check that changing one card style does not alter navigation or form controls. Extension: implement a theme using token overrides and recheck contrast for every state.

## Completion evidence
